# Homebrew tap for ProxyZip

[ProxyZip](https://github.com/LuisPeixoto/ProxyZip) is an open-source debugging proxy: capture, inspect and debug HTTP(S) traffic.

```bash
brew tap LuisPeixoto/proxyzip

brew install --cask proxyzip      # the desktop app
brew install proxyzip-cli         # the command-line tool
```

The files here are generated from each ProxyZip release, so please report problems in the
[main repository](https://github.com/LuisPeixoto/ProxyZip/issues).
